# דשבורד שווקים · פורטה

אתר פנימי עם שש לשוניות, וכתובתו https://forte-markets.forte-iem.workers.dev:

- **סנטימנט:** כ-35 אינדיקטורים, לכל אחד אחוזון ו-Z מול ההיסטוריה שלו, מדד סנטימנט משוקלל, ומה עשה S&P 500 אחרי קריאות דומות.
- **מדדים מובילים:** מצב טכני של כ-50 מדדים בעולם (מגמה, ממוצעים, RSI, מרחק מהשיא), וגם אג"ח, סחורות ומטבעות.
- **מומנטום:**
  - 31 פקטורים, 18 סקטורים ותעשיות ו-19 נושאים מול S&P 500, עם RS, מפת רוטציה וקורלציות.
  - RS לכל המניות בשוק (כ-3,500 מניות): דירוג סקטורים, חיפוש וסינון לפי סקטור, שווי שוק ו-RS מינימלי, ותצוגת S&P 500 לפי GICS.
  - מומנטום 12-1 של המדדים בעולם.
  - המניות החזקות והחלשות ב-S&P 500 במומנטום 12-1, ואיפה המומנטום מרוכז.
- **מאקרו:** אינפלציה בארה"ב ובישראל, ריבית הפד ובנק ישראל, עקום התשואות, מרווחי אשראי לפי דירוג (AAA עד CCC) ואג"ח זבל, דירוג המרווחים שהתרחבו והצטמצמו הכי הרבה, שוק העבודה (אבטלה, משרות, תביעות), M2, סחורות, דלק, חשמל סיטונאי ומרווח ספארק.
- **ישראל:** מדד סנטימנט ישראלי (10 רכיבים), רוחב שוק ממדגם של כ-80 מניות גדולות בת"א, תנודתיות ת"א 35, הובלת הבנקים, זרימת כסף ל-EIS, השקל, 12 סקטורים, RS למניות, ומאקרו (ריבית, אינפלציה, אג"ח 10 שנים והפער מול ארה"ב, אבטלה, מחירי דירות). ההגדרות ב-`config/israel.json`.
- **ניתוחים טכניים:** צילום גרף מ-TradingView, רמות ושורה תחתונה לכל מניה בתיק.

## ארכיטקטורה (₪0)

| רכיב | איפה | מה הוא עושה |

| `forte-markets-update` | GitHub Actions | כל לילה, שני–שישי ב-21:47 UTC, ועוד ריצה בבוקר (שלישי–שבת ב-10:23 UTC) בשביל טבלת ה-RS. מושך את כל המקורות, מעדכן את `data/`, בונה את האתר ופורס |
| `data/series/*.csv` | המאגר | ההיסטוריה של כל אינדיקטור. כל ריצה היא commit, אז גם הגיבוי מובנה |
| `data/prices/close.csv` | המאגר | סגירות יומיות של המדדים, הפקטורים והסקטורים |
| `data/derived/rs*.json`, `rs_dist.csv`, `rs_etf.csv` | המאגר | טבלת ה-RS של המניות, ה-RS של תעודות הסל, וההתפלגות היומית שממנה מחושבת היסטוריית ה-RS |
| אתר + API | Cloudflare Worker `forte-markets` | מגיש את האתר. ב-KV נשמרים הניתוחים, הגרפים, השורה התחתונה והנתונים הידניים |

| מדדים, פקטורים, סקטורים, MOVE, יחסים | Yahoo Finance דרך yfinance |
| רוחב שוק (% מעל ממוצעים, עולות/יורדות, שיאים/שפלים, McClellan) | מחושב מסגירות 500 רכיבי S&P 500. רשימת הרכיבים: `datasets/s-and-p-500-companies` |
| RS לכל מניה | צילומי המצב היומיים של רשימת המניות של NASDAQ בהיסטוריה של `ozkanpakdil/top-us-stock-tickers` (OHLC, שווי שוק, סקטור). למניות S&P 500: נרות יומיים מ-Yahoo, שמשמשים גם לבדיקת כל צילום |

כל מקור נבדק לפני כתיבה (טווחים סבירים, התאמה להיסטוריה שכבר קיימת).

**RS:** מהלך ב-ATR = ‏(Close<sub>t</sub> − Close<sub>t−10</sub>) / ATR(10), ‏RS = האחוזון של המהלך מול כל המניות שדורגו, 1–100. תעודות הסל מדורגות מול אותה התפלגות, כך ש-RS של פקטור ושל מניה על אותו סולם. צילום שלא תואם ל-Yahoo בסגירות של מניות S&P 500 נדחה, ומניות עם פיצול בתוך החלון מוצאות. כשל במקור אחד לא עוצר את האחרים, והוא מוצג בלשונית הניהול ובפס התראה באתר.

## הוספת מדד או אינדיקטור

- **מדד, פקטור, סקטור או נושא חדש:** מוסיפים שורה ל-`config/universe.json` עם סימול של Yahoo. הריצה הבאה משלימה לו היסטוריה מ-2013. בקבוצה של יותר מ-14 פריטים, `"core": true` קובע מי מופיע במפת הרוטציה ובמפת הקורלציות.
- **אינדיקטור סנטימנט אוטומטי חדש:** מוסיפים הגדרה ל-`config/indicators.json` ומקור ל-`pipeline/`.
- **אינדיקטור ידני:** מוסיפים אותו מהאתר, במצב עורך. בלשונית ניהול לוחצים "אינדיקטור חדש", ואז מזינים ערכים או מייבאים CSV.
