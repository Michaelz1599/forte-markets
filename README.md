# דשבורד שווקים · פורטה

אתר פנימי עם שלוש לשוניות:

- **סנטימנט:** כ-35 אינדיקטורים, לכל אחד אחוזון ו-Z מול ההיסטוריה שלו, מדד סנטימנט משוקלל, ומה עשה S&P 500 אחרי קריאות דומות.
- **מדדים מובילים:** מצב טכני של המדדים בארה"ב, ישראל, אירופה ואסיה, וגם אג"ח, סחורות ומטבעות. בנוסף מומנטום לפי פקטור וסקטור, מפת רוטציה וקורלציות.
- **ניתוחים טכניים:** צילום גרף מ-TradingView, רמות ושורה תחתונה לכל מניה בתיק.

## ארכיטקטורה (₪0)

| רכיב | איפה | מה הוא עושה |
|---|---|---|
| `forte-markets-update` | GitHub Actions | כל לילה, שני–שישי ב-21:47 UTC. מושך את כל המקורות, מעדכן את `data/`, בונה את האתר ופורס |
| `data/series/*.csv` | המאגר | ההיסטוריה של כל אינדיקטור. כל ריצה היא commit, אז גם הגיבוי מובנה |
| `data/prices/close.csv` | המאגר | סגירות יומיות של המדדים, הפקטורים והסקטורים |
| אתר + API | Cloudflare Worker `forte-markets` | מגיש את האתר. ב-KV נשמרים הניתוחים, הגרפים, השורה התחתונה והנתונים הידניים |

כל מקור נבדק לפני כתיבה (טווחים סבירים, התאמה להיסטוריה שכבר קיימת). כשל במקור אחד לא עוצר את האחרים, והוא מוצג בלשונית הניהול ובפס התראה באתר.

## הוספת מדד או אינדיקטור

- **מדד, פקטור או סקטור חדש:** מוסיפים שורה ל-`config/universe.json` עם סימול של Yahoo. הריצה הבאה משלימה לו היסטוריה מ-2013.
- **אינדיקטור סנטימנט אוטומטי חדש:** מוסיפים הגדרה ל-`config/indicators.json` ומקור ל-`pipeline/`.
- **אינדיקטור ידני:** מוסיפים אותו מהאתר, במצב עורך. בלשונית ניהול לוחצים "אינדיקטור חדש", ואז מזינים ערכים או מייבאים CSV.

## הרצה מקומית

```bash
pip install -r requirements.txt pytest
python -m pytest -q tests
python -m pipeline.run            # ריצה מלאה, כמו ב-GitHub
python -m pipeline.run --offline  # בנייה מחדש מהנתונים השמורים, בלי רשת
```

## סודות ב-GitHub

- `CLOUDFLARE_API_TOKEN`: תבנית "Edit Cloudflare Workers", כולל Workers KV Storage: Edit.
- `CLOUDFLARE_ACCOUNT_ID`.
- `EDITOR_CODE`: הסיסמה לעריכה באתר. ב-Worker נשמר רק ה-hash שלה.
